## 为什么重新设计

上一轮（`design-demos/` 下的旧三版）与本轮**无关**，未复用任何结构、配色或组件。本轮从零开始：
先考考古真实产品内容，再从两个莱茵生命开源复刻项目提取视觉语法，最后按「最佳设计师 / 现实参照 /
秒数轮盘」三套逻辑各出两个候选。

## 三个方向

### A1 · 白室导视 White Room Signage
- **来源**：Otl Aicher（慕尼黑 1972 奥运视觉系统、ERCO 企业系统、法兰克福机场导视）
- **借的**：无框分区只靠 1px 线；每个功能区一个几何原型图标；01–04 编号压角；大标题走英文、中文只做并置；
  一条**从右向左量出来的 1px 线** + 末端 6×6 角标（1.3s 入场）
- **主角素材**：程序化几何原型图标（纯 CSS），被截取的屏幕内容用渐变+网格诚实示意
- **骨架**：纸底 + 左上巨型英文标题 + 四格等分目的地 + 页脚仪器状态行
- **form 来自内容的哪里**：28 项能力天然落成「截取 / 读取 / 固定 / 归档」四个目的地，导视语法就是这款产品真实的导航结构

### B1 · 工作站 Workstation
- **来源**：Ableton Live 12（Berlin）的桌面创作工具语言
- **借的**：暖灰三阶造深度（零阴影零圆角）；左侧分组浏览器 + 选中项 2px 橙条；内容区并列 lane + 角标计数；底部传输条
- **主角素材**：真实 28 项功能清单 + 出厂热键比 3/27
- **骨架**：标题栏 + 224px 左栏浏览器 + 双 lane 高密度工作台 + 字段行 + 传输条
- **form 来自内容的哪里**：13 个路由里 5 个本就是功能页（翻译/AI/历史/搜索/剪贴板），它更像一台常开的工作台而非设置页

### C2 · 观测环盘 Observation Ring
- **来源**：杉浦康平信息曼荼罗（同心环盘 = 导航）+ 官方「双环 + 正负号」标志构成语法
- **借的**：四能力沿圆周分布；外环 60 格刻度、当前扇区刻度加高；环心为当前项；竖排中文标题 + 横排全大写英文小标；四角 HUD；朱红仅 2 处做扇区标记
- **主角素材**：纯 CSS/SVG 程序化几何（annulus 路径 + conic-gradient + 沿圆周 textPath）
- **骨架**：暗底满屏 + 居中环盘 + 右侧详情 + 左下巨计数 + 页脚状态行；←/→ 绕环、Enter 确认
- **form 来自内容的哪里**：截图→识别→归档→再截图的真实动作闭环，环盘画的就是这个循环

## 品牌色怎么处理

莱茵生命的官方「配色」其实是**黑白 + 一点橙**。两套复刻项目各有一套精确 token：

| | 亮底（白室终端） | 暗底（观测室） |
|---|---|---|
| 纸/底 | `#EAE5E1` | `#11181B` |
| 面板 | `#EDEBE4` | `#202A2F` |
| 墨 | `#080A08` | `#E0E3DC` |
| 发丝线 | `#AAA59A` | `#536166` |
| 强调 | `#9B7247`（暖铜） | `#C5A16B`（琥珀） |
| 警示/信号 | `#F2B800` | `#FF7A01` |

三个方向**各自只用一个强调色**：A1 暖铜、B1 信号橙（RhinE 源码精确值 `#FF7A01`）、C2 琥珀 + 朱红 `#9E2A1D` 标记。
原设计的 `#1677ff` Ant 蓝与 `#8b5cf6` 紫全部废弃。

## 三版共用的硬约束（全部实测通过）

- `design_lint.py check`：**零红灯**。黄灯仅「全大写拉字距小标」（正是本风格的核心语法）与「01/02/03 编号」（真实序列）
- `design_lint.py compare --brand`：**三版拉开了**（色板距离 0.022~0.564，骨架相关 -0.02~0.27）
- Playwright 实测：三版均 `scrollWidth=1600 / scrollHeight=1000`、逐元素扫描 **0 处出界**、**console 零报错**、**零圆角**
- 最小字号 12px，正文行 ≥14px，`font-variant-numeric: tabular-nums` 全局
- 零外部依赖：无 Google Fonts CDN、无外链图片、无 `mask:url()`、无 emoji；字体全走系统栈（微软雅黑 / 等线 / Bahnschrift / Consolas）
- 交互：A1 12 个、B1 13 个、C2 20 个可交互点，全部 Playwright 逐个点过
