# 方向卡 · A1 · 哑光器物 MATTE

| 栏 | 内容 |
|---|---|
| 逻辑与来源 | **最佳设计师 · 深泽直人（Naoto Fukasawa，1956– ，东京）**。他的方法不是「做造型」，而是让形式从使用里自己长出来（"without thought" / 无意识设计）：MUJI 壁挂 CD 播放器（1999，拉绳即播放）、±0 加湿器（2003）。材质处理上偏爱哑光、细砂面、无装饰的白色与灰色。 |
| 借的是什么 | ① **材质诚实**：每一种表面只说自己是什么——细砂面塑料、阳极氧化铝、印刷丝印，不做假的玻璃与假的光；② **没有装饰性高光**，只有材料本身在光下的极低反差渐变；③ **一个动作一个物件**：主操作是一个被压下去就下去的实体按键，不是一个会发光的按钮；④ 颜色只有「本体色 + 一个印刷色」。 |
| 主角素材 | **程序化材质**：用 SVG feTurbulence 生成 3% 透明度的细砂噪点铺在表面（这是要「摸得到」的那一层），配合 1px 机加工接缝与 2px 凹槽。零截图、零插画。 |
| 骨架 | 主窗口＝**一台设备的面板**：左侧 208px 是「机身侧边」（深一档的哑光面 + 内嵌接缝），右侧是「面板」（浅一档），顶部一条 44px 铭牌行放字标与状态读数；内容区是一整张纸，用横向接缝分节，不用卡片投影。 |
| 胆量花在哪 | **全界面没有一个渐变按钮、没有一处发光**：所有层级由「表面明度 + 接缝 + 极细砂面」三样东西表达。选中的那一项不是变亮，而是被「压进」面板（内阴影 1px）。 |
| form 来自内容的哪里 | 截图工具的每次动作都对应一个**物理手势**：框选＝在屏幕上拉一个框、标注＝在图上落笔、贴图＝把一块纸钉在桌上。所以界面里所有「当前工具」都做成凹槽里的一枚键帽，而不是一个高亮的文字标签。 |
| 温度在哪 | 暖不是靠色相：暖来自**低反光的表面**和**接缝的阴影**——像一支用得久了、边角被磨圆的金属笔。 |
| 风险 | 太安静时容易被读成「旧版换了配色」。对策：把层级的差别做在**表面台阶**（4 档明度，每档 4–5 点 L 差）与**接缝方向**（水平接缝＝分节，垂直接缝＝分栏），而不是做在描边上。 |
