# 方向卡 · A2 · 一体成型 UNIBODY

| 栏 | 内容 |
|---|---|
| 逻辑与来源 | **最佳设计师 · Jony Ive 时代的 Apple 一体成型（unibody）工业设计**：2008 款 MacBook 起，机身由一整块铝铣出，边缘倒角（chamfer）形成一条沿轮廓的高光；元素之间用「同材质、同曲面」连成一件东西，分隔靠的是**曲面变化**而不是加线。 |
| 借的是什么 | ① 一条 1px 的**倒角高光**沿每个表面轮廓走一圈（`inset 0 1px 0 rgba(255,255,255,.7)` + `inset 0 -1px 0 rgba(0,0,0,.10)`）；② 大曲率连续圆角（半径 14–18px，内外同圆心）；③ 深色时用「阳极氧化黑」而不是纯黑；④ 控件是一个整体面，不是拼图。 |
| 主角素材 | **程序化高光**：每个表面的倒角高光由 CSS 多层 inset shadow 合成，随主题切换改变方向（亮＝上亮下暗，暗＝上暗下亮）。 |
| 骨架 | 主窗口是一整块「机身」：侧栏与内容区共享同一个外壳曲面，中间没有分隔线，只有一条 1px 的凹陷沟槽；工具条嵌在底边内圈。 |
| 胆量花在哪 | **取消所有卡片**：整个界面只有一块材料，内容直接落在材料上。 |
| form 来自内容的哪里 | 截图工具本身是一件「硬件配套软件」——它操作的是屏幕这块发光表面；一体成型的连续曲面，正好回应「软件是硬件的延伸」。 |
| 未做完整版的原因 | 与 A1 同属「机加工表面」家族，两个一起做成完整版会撞外观（`design_lint compare` 也会报）。它的强项（倒角高光、连续曲面）作为 A1 的参考被吸收。 |
