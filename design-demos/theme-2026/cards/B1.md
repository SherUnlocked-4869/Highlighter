# 方向卡 · B1 · 浮层优先 FILM

| 栏 | 内容 |
|---|---|
| 逻辑与来源 | **现实参照 · CleanShot X（MTW，macOS 截图工具）**。同一媒介、同一品类的成熟作品：截图完成后浮出一个深色圆角控制面板，动作是一排圆形按钮，面板浮在截图之上而不是弹窗盖住它；macOS 原生质感、圆角、柔和阴影。已核实官网在线（<https://cleanshot.com/>，2026-10-23 抓取；截图已从仓库删除）。 |
| 借的是什么 | ① **浮层是主角**：产品的主界面其实是「屏幕上那一小块玻璃」，主窗口只是它的设置面；② 浮层用**圆角 + 双层阴影 + 半透明 + 背后模糊**表达「悬浮」，而不是描边；③ 动作排成一行，主操作最大、最亮；④ 大留白与高对比正文，界面越少越好。 |
| 主角素材 | **被截取的屏幕本身**：浮层演示区用 CSS 画一块有内容的「桌面」（两块窗口 + 一行标题栏 + 一段正文），让半透明面板真的有东西可透、可糊。这是截图工具天生独有的素材。 |
| 骨架 | 主窗口＝一块安静的设置面：左侧 220px 列表 + 右侧单栏内容，内容区的卡片彼此**浮在不同高度**（用阴影深度分级，不用边框分级），窗口本身无边框、圆角 16px、外阴影落在桌面背景上。 |
| 胆量花在哪 | **把「浮层」当成整套语言的语法**：主窗口里的浮层（下拉、工具条、选区提示）全部沿用同一套玻璃与阴影规则，于是设置界面看起来像它自己浮在桌面上——一套语言，不是两套。 |
| form 来自内容的哪里 | 截图工具真正的界面 99% 的时间只有一块浮层（框选 + 工具条），主窗口一年开不了几次；把浮层做成主角，是这个产品独有的界面真相。 |
| 温度在哪 | 玻璃不是冷色玻璃：底色是**暖中性**（微黄灰），玻璃里带一点温度；模糊半径大一点（18–24px），边缘柔和，摸起来像一层薄的磨砂亚克力。 |
