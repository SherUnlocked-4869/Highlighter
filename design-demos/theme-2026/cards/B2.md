# 方向卡 · B2 · 原生精修 PAPER

| 栏 | 内容 |
|---|---|
| 逻辑与来源 | **现实参照 · Things 3（Cultured Code，斯图加特）**。两获 Apple Design Award 的个人任务应用；官网引用的评价是它的界面「像一张干净挺括的纸」。已核实官网在线（<https://culturedcode.com/things/>，2026-10-23 抓取；截图已从仓库删除）。 |
| 借的是什么 | ① 纯白底 + 近黑字 + **只有一个蓝**只给可点的东西；② 行与行之间一条**从复选框右侧起**的缩进发丝线，而不是完整的分隔；③ 分组标题是小号粗体，不加任何装饰；④ 大标题 32px、紧字距；⑤ 展开的任务变成一张有双层阴影的浮起卡片。 |
| 主角素材 | **排版本身**：没有图，全部靠字号、字重、行高与那一条缩进的线。 |
| 骨架 | 侧栏 + 纯文字列表；列表行高 44px，行内三段（图标 / 名称 / 右侧快捷键），快捷键右对齐形成一条看不见的竖线。 |
| 胆量花在哪 | **几乎没有样式**：没有卡片底、没有圆角容器、没有彩色分类，只有一条蓝。 |
| form 来自内容的哪里 | 截图历史与动作列表本质上都是「一行一行的条目」；Things 的条目语法正好装下 27 个功能与 42 条剪贴记录。 |
| 未做完整版的原因 | 它太接近「桌面软件原生感」这个安全答案，与 B1 同属「亮色、克制、列表」骨架；作为 B1 的排印参照被吸收（大标题字阶、缩进分隔线）。 |
