# 方向卡 · C2 · 珐琅铭牌 ENAMEL

| 栏 | 内容 |
|---|---|
| 逻辑与来源 | **秒数轮盘 · 东亚区 6 号「香港街招与招牌」**。原风格是深夜墙面层层叠叠的霓虹招牌（高饱和纯底 + 奶白边框 + 硬投影 + 繁粗黑字）。我抽到它时判断：整页做成霓虹招牌一定是过头（去掉霓虹，信息并不会更清楚）。所以只取其中**与「器物」有关的三个做法**：① 字是「刻/印」在材料上的，不是浮在背景上的；② 每一块信息有明确的**牌面边界**（一道奶白描边 + 一道内阴影，像珐琅牌子的折边）；③ 高对比的暖白与近黑。 |
| 借的是什么 | ① **牌面（plate）**：信息分组不是卡片，是「一块被固定在面板上的铭牌」——1px 奶白描边 + 内阴影 + 4–8px 圆角；② 正文用**宋体**刻字（Noto Serif SC），标签用黑体丝印；③ 只有两种"活"的颜色：朱红（当前）与黄铜（一次性的分隔线）；④ 阴影方向一致（光从左上来），所有牌面共享同一光源。 |
| 主角素材 | **材料与光**：近黑珐琅面（`linear-gradient` 极缓的明度变化 + 细噪点），牌面的奶白描边与内阴影；不用图。 |
| 骨架 | 主窗口＝一块深色珐琅控制面板：顶部一条铭牌放字标，左侧一列「刻字」导航（选中项是一块被点亮的牌），内容区是一组大小不一的牌面拼贴（不是整齐的卡片网格）。 |
| 胆量花在哪 | **深色是默认**，且正文用宋体——一个效率工具敢用宋体做正文，是因为它把界面当成一块「刻着字的牌」，而不是一块屏幕。 |
| form 来自内容的哪里 | 截图工具输出的是一张**被装裱起来的图**；它的历史、它的贴图、它的识别结果，最后都变成「一块牌子」贴在桌面上。 |
| 温度在哪 | 暖来自**光源**（左上偏暖的光 + 右下较深的阴影），不是来自底色；朱红只出现在「正在用的是这个」，像落款的一枚印。 |
| 风险 | 深色 + 宋体容易被读成「复古」。对策：几何完全是现代的（8px 圆角、无衬线数字、等距网格），只有字与牌面是旧的——新旧之间的张力就是高级感。 |
