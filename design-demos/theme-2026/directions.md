## 上一轮为什么被否（写在这里，三个方向都不许重犯）

用户对上轮莱茵生命三版的判词是「都不太行，全都舍弃吧」。复盘出来的具体原因，这一轮全部反向处理：

| 上轮做法 | 为什么在高频工具里失效 | 本轮的反向约束 |
|---|---|---|
| 零圆角、1px 发丝线 | 边界太弱，27 个控件扫读要靠猜 | 圆角与厚度必须有，边界要能被手指记住 |
| 9–11px 微标签、全大写宽字距 | 中文在 11px 下糊成一团 | 标签 ≥12px，中文标签不用宽字距 |
| 低对比暖灰 + 单色 | 每天开合几十次，找东西成本高 | 正文对比度 ≥4.5:1，层级靠明度台阶与材质，不靠压低对比 |
| 机构档案的冷感 | 用户要的是「一件真实的器物」，不是展签 | 温度来自材质与手感，不来自配色变暖 |

## A1 · 哑光器物 MATTE　【完整版 dir-1.html】

| 栏 | 内容 |
|---|---|
| 逻辑与来源 | **最佳设计师 · 深泽直人（Naoto Fukasawa，1956– ，东京）**。他的方法不是「做造型」，而是让形式从使用里自己长出来（"without thought" / 无意识设计）：MUJI 壁挂 CD 播放器（1999，拉绳即播放）、±0 加湿器（2003）。材质处理上偏爱哑光、细砂面、无装饰的白色与灰色。 |
| 借的是什么 | ① **材质诚实**：每一种表面只说自己是什么——细砂面塑料、阳极氧化铝、印刷丝印，不做假的玻璃与假的光；② **没有装饰性高光**，只有材料本身在光下的极低反差渐变；③ **一个动作一个物件**：主操作是一个被压下去就下去的实体按键，不是一个会发光的按钮；④ 颜色只有「本体色 + 一个印刷色」。 |
| 主角素材 | **程序化材质**：用 SVG feTurbulence 生成 3% 透明度的细砂噪点铺在表面（这是要「摸得到」的那一层），配合 1px 机加工接缝与 2px 凹槽。零截图、零插画。 |
| 骨架 | 主窗口＝**一台设备的面板**：左侧 208px 是「机身侧边」（深一档的哑光面 + 内嵌接缝），右侧是「面板」（浅一档），顶部一条 44px 铭牌行放字标与状态读数；内容区是一整张纸，用横向接缝分节，不用卡片投影。 |
| 胆量花在哪 | **全界面没有一个渐变按钮、没有一处发光**：所有层级由「表面明度 + 接缝 + 极细砂面」三样东西表达。选中的那一项不是变亮，而是被「压进」面板（内阴影 1px）。 |
| form 来自内容的哪里 | 截图工具的每次动作都对应一个**物理手势**：框选＝在屏幕上拉一个框、标注＝在图上落笔、贴图＝把一块纸钉在桌上。所以界面里所有「当前工具」都做成凹槽里的一枚键帽，而不是一个高亮的文字标签。 |
| 温度在哪 | 暖不是靠色相：暖来自**低反光的表面**和**接缝的阴影**——像一支用得久了、边角被磨圆的金属笔。最终调色因此走了**阳极氧化冷银**（#d3d6d9 / #bfc2c7 / #828a93 / 台面 #7e8388），暖只留在那个唯一的印刷色 #e5a44c 上：「冷金属上的一块丝印橙」比「暖灰底上的暖橙」更像器物。 |
| 风险 | 太安静时容易被读成「旧版换了配色」。对策：把层级的差别做在**表面台阶**（4 档明度，每档 4–5 点 L 差）与**接缝方向**（水平接缝＝分节，垂直接缝＝分栏），而不是做在描边上。 |

## A2 · 一体成型 UNIBODY　【备选】

| 栏 | 内容 |
|---|---|
| 逻辑与来源 | **最佳设计师 · Jony Ive 时代的 Apple 一体成型（unibody）工业设计**：2008 款 MacBook 起，机身由一整块铝铣出，边缘倒角（chamfer）形成一条沿轮廓的高光；元素之间用「同材质、同曲面」连成一件东西，分隔靠的是**曲面变化**而不是加线。 |
| 借的是什么 | ① 一条 1px 的**倒角高光**沿每个表面轮廓走一圈（`inset 0 1px 0 rgba(255,255,255,.7)` + `inset 0 -1px 0 rgba(0,0,0,.10)`）；② 大曲率连续圆角（半径 14–18px，内外同圆心）；③ 深色时用「阳极氧化黑」而不是纯黑；④ 控件是一个整体面，不是拼图。 |
| 主角素材 | **程序化高光**：每个表面的倒角高光由 CSS 多层 inset shadow 合成，随主题切换改变方向（亮＝上亮下暗，暗＝上暗下亮）。 |
| 骨架 | 主窗口是一整块「机身」：侧栏与内容区共享同一个外壳曲面，中间没有分隔线，只有一条 1px 的凹陷沟槽；工具条嵌在底边内圈。 |
| 胆量花在哪 | **取消所有卡片**：整个界面只有一块材料，内容直接落在材料上。 |
| form 来自内容的哪里 | 截图工具本身是一件「硬件配套软件」——它操作的是屏幕这块发光表面；一体成型的连续曲面，正好回应「软件是硬件的延伸」。 |
| 未做完整版的原因 | 与 A1 同属「机加工表面」家族，两个一起做成完整版会撞外观（`design_lint compare` 也会报）。它的强项（倒角高光、连续曲面）作为 A1 的参考被吸收。 |

## B1 · 浮层优先 FILM　【完整版 dir-2.html】

| 栏 | 内容 |
|---|---|
| 逻辑与来源 | **现实参照 · CleanShot X（MTW，macOS 截图工具）**。同一媒介、同一品类的成熟作品：截图完成后浮出一个深色圆角控制面板，动作是一排圆形按钮，面板浮在截图之上而不是弹窗盖住它；macOS 原生质感、圆角、柔和阴影。已核实官网在线（`https://cleanshot.com/`，2026-10-23 抓取，见 `refs/cleanshot-home.png`）。 |
| 借的是什么 | ① **浮层是主角**：产品的主界面其实是「屏幕上那一小块玻璃」，主窗口只是它的设置面；② 浮层用**圆角 + 双层阴影 + 半透明 + 背后模糊**表达「悬浮」，而不是描边；③ 动作排成一行，主操作最大、最亮；④ 大留白与高对比正文，界面越少越好。 |
| 主角素材 | **被截取的屏幕本身**：浮层演示区用 CSS 画一块有内容的「桌面」（两块窗口 + 一行标题栏 + 一段正文），让半透明面板真的有东西可透、可糊。这是截图工具天生独有的素材。 |
| 骨架 | 主窗口＝一块安静的设置面：左侧 220px 列表 + 右侧单栏内容，内容区的卡片彼此**浮在不同高度**（用阴影深度分级，不用边框分级），窗口本身无边框、圆角 16px、外阴影落在桌面背景上。 |
| 胆量花在哪 | **把「浮层」当成整套语言的语法**：主窗口里的浮层（下拉、工具条、选区提示）全部沿用同一套玻璃与阴影规则，于是设置界面看起来像它自己浮在桌面上——一套语言，不是两套。 |
| form 来自内容的哪里 | 截图工具真正的界面 99% 的时间只有一块浮层（框选 + 工具条），主窗口一年开不了几次；把浮层做成主角，是这个产品独有的界面真相。 |
| 温度在哪 | 玻璃不是冷色玻璃：底色是**暖中性**（微黄灰），玻璃里带一点温度；模糊半径大一点（18–24px），边缘柔和，摸起来像一层薄的磨砂亚克力。 |

## B2 · 原生精修 PAPER　【备选】

| 栏 | 内容 |
|---|---|
| 逻辑与来源 | **现实参照 · Things 3（Cultured Code，斯图加特）**。两获 Apple Design Award 的个人任务应用；官网引用的评价是它的界面「像一张干净挺括的纸」。已核实官网在线（`https://culturedcode.com/things/`，2026-10-23 抓取，见 `refs/things-home.png`）。 |
| 借的是什么 | ① 纯白底 + 近黑字 + **只有一个蓝**只给可点的东西；② 行与行之间一条**从复选框右侧起**的缩进发丝线，而不是完整的分隔；③ 分组标题是小号粗体，不加任何装饰；④ 大标题 32px、紧字距；⑤ 展开的任务变成一张有双层阴影的浮起卡片。 |
| 主角素材 | **排版本身**：没有图，全部靠字号、字重、行高与那一条缩进的线。 |
| 骨架 | 侧栏 + 纯文字列表；列表行高 44px，行内三段（图标 / 名称 / 右侧快捷键），快捷键右对齐形成一条看不见的竖线。 |
| 胆量花在哪 | **几乎没有样式**：没有卡片底、没有圆角容器、没有彩色分类，只有一条蓝。 |
| form 来自内容的哪里 | 截图历史与动作列表本质上都是「一行一行的条目」；Things 的条目语法正好装下 27 个功能与 42 条剪贴记录。 |
| 未做完整版的原因 | 它太接近「桌面软件原生感」这个安全答案，与 B1 同属「亮色、克制、列表」骨架；作为 B1 的排印参照被吸收（大标题字阶、缩进分隔线）。 |

## C1 · 斜切流光 CHAMFER　【备选】

| 栏 | 内容 |
|---|---|
| 逻辑与来源 | **秒数轮盘 · 网页区 14 号「斜切流体渐变带 Angled Fluid Gradient」**（参考 Stripe 的斜切渐变 banner 与 Klim 定制 Söhne 的排印）。轮盘抽到它时我的第一反应是「这是落地页语言，不是工具语言」，所以只取其中**可迁移的一条**：斜切（skew / clip-path）作为分隔方式。 |
| 借的是什么 | ① 45° 斜切的分区边界；② 一条缓慢流动的两色渐变只在**一个**位置出现（主窗标题区）；③ 斜切面之间靠明度差而不是线。 |
| 主角素材 | 程序化渐变（conic + linear 叠加，`background-size` 大倍率缓慢移动）。 |
| 骨架 | 主窗口用一条斜切把「导航」与「内容」分开，内容区被斜切成三条速度不同的带。 |
| 胆量花在哪 | 斜切贯穿全窗口，包括列表行。 |
| form 来自内容的哪里 | 截图之后会被缩放、旋转、透视变形——斜切是「图像变换」这件事在界面上的回声。 |
| 未做完整版的原因 | 去掉斜切之后信息反而更清楚（列表本来就该是水平的），说明这个手法是「用力过头」；而且渐变在暗色浮层上会破坏可读性。**保留它作为三版里唯一的「过头」候选，用来给用户看边界在哪。** |

## C2 · 珐琅铭牌 ENAMEL　【完整版 dir-3.html】

| 栏 | 内容 |
|---|---|
| 逻辑与来源 | **秒数轮盘 · 东亚区 6 号「香港街招与招牌」**。原风格是深夜墙面层层叠叠的霓虹招牌（高饱和纯底 + 奶白边框 + 硬投影 + 繁粗黑字）。我抽到它时判断：整页做成霓虹招牌一定是过头（去掉霓虹，信息并不会更清楚）。所以只取其中**与「器物」有关的三个做法**：① 字是「刻/印」在材料上的，不是浮在背景上的；② 每一块信息有明确的**牌面边界**（一道奶白描边 + 一道内阴影，像珐琅牌子的折边）；③ 高对比的暖白与近黑。 |
| 借的是什么 | ① **牌面（plate）**：信息分组不是卡片，是「一块被固定在面板上的铭牌」——1px 奶白描边 + 内阴影 + 4–8px 圆角；② 正文用**宋体**刻字（Noto Serif SC），标签用黑体丝印；③ 只有两种"活"的颜色：朱红（当前）与黄铜（一次性的分隔线）；④ 阴影方向一致（光从左上来），所有牌面共享同一光源。 |
| 主角素材 | **材料与光**：近黑珐琅面（`linear-gradient` 极缓的明度变化 + 细噪点），牌面的奶白描边与内阴影；不用图。 |
| 骨架 | 主窗口＝一块深色珐琅控制面板：顶部一条铭牌放字标，左侧一列「刻字」导航（选中项是一块被点亮的牌），内容区是一组大小不一的牌面拼贴（不是整齐的卡片网格）。 |
| 胆量花在哪 | **深色是默认**，且正文用宋体——一个效率工具敢用宋体做正文，是因为它把界面当成一块「刻着字的牌」，而不是一块屏幕。 |
| form 来自内容的哪里 | 截图工具输出的是一张**被装裱起来的图**；它的历史、它的贴图、它的识别结果，最后都变成「一块牌子」贴在桌面上。 |
| 温度在哪 | 暖来自**光源**（左上偏暖的光 + 右下较深的阴影），不是来自底色；朱红只出现在「正在用的是这个」，像落款的一枚印。 |
| 风险 | 深色 + 宋体容易被读成「复古」。对策：几何完全是现代的（8px 圆角、无衬线数字、等距网格），只有字与牌面是旧的——新旧之间的张力就是高级感。 |

## 六张缩略图 → 选三张

缩略图见 `thumbs.html`（渲染结果 `shots/thumbs.png`），每格是这个方向最关键的一屏（主窗口内容区 + 导航）。

选择标准按顺序：单看够好 → 三张彼此不一样 → 不撞外观账本（上一轮：浅暖纸底 / 灰底 / 近黑底 + 无衬线标题 3/3）→ 最多一张用力过头。

| 文件 | 方向 | 温度 | 骨架 | 明暗默认 | 来源 |
|---|---|---|---|---|---|
| `dir-1.html` | A1 哑光器物 | 安静·克制 | 设备面板：机身侧边 + 面板 + 铭牌行 | 亮 | 深泽直人 |
| `dir-2.html` | B1 浮层优先 | 中性·轻盈 | 无边框窗口 + 不同投影高度的浮面 | 亮 | CleanShot X |
| `dir-3.html` | C2 珐琅铭牌 | 大胆·有光 | 深色珐琅面板 + 牌面拼贴 | 暗 | 香港街招（只取"刻字 + 牌面"） |

三张彼此：**哑光 / 玻璃 / 珐琅**；**机加工 / 悬浮 / 刻印**；**亮 / 亮 / 暗**；**安静 / 中性 / 大胆**。
三张里没有一张落在「暖奶油底 + 衬线标题 + 陶土色」这组 2026 年 AI 默认外观里；字体上 A、B 用无衬线标题，C 用宋体标题，避开了上一轮「无衬线 3/3」。
