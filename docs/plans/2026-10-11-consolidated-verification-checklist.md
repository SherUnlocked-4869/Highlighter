
## 3. 批次 B 真机项

### 3.1 录屏音轨（S2 · T8）

**步骤**：设置页「视频录制」卡片确认三个开关（**系统声音**=开、**麦克风**=关、「截图带光标」在「截图与输出」卡片）→ 对每个组合录 **10 秒**（播放一段有声音的视频/音乐以便核对）→ 保存 MP4。

| 组合 | 设置 | 期望 |
| --- | --- | --- |
| ① | 系统声开 / 麦克风关（默认） | MP4 **有音轨**（aac 48kHz stereo 160k）；能听到系统声 |
| ② | 系统声开 / 麦克风开 | MP4 有音轨，**两者混音**都在 |
| ③ | 系统声关 / 麦克风开 | MP4 有音轨，只有麦克风 |
| ④ | 两个都关 | MP4 **无音轨**（ffmpeg 走 `-an`）；文件仍可正常播放画面 |

**取证**：`ffmpeg -i out.mp4` 看 `Stream #0:1: Audio: aac (LC), 48000 Hz, stereo, 160 kb/s`；组合④应**只有** `Stream #0:0: Video`。
**附加**：录制中拔/插耳机 → 状态栏应出现降级提示（「麦克风已断开…」/「系统声音已中断…」），且**录制不中断**。
**已知边界**：麦克风失败 → 仅系统声；系统声失败 → 仅麦克风；都失败 → 无声视频 + 状态栏明示。

### 3.2 截图带光标（S5 + S9b · T6）

**步骤**：设置页「截图与输出」→ 开「**截图带光标**」→ `Ctrl+1` 截一张（让光标停在选区内）→ 保存；再关掉开关截一张同样的。

| # | 期望 | 取证 |
| --- | --- | --- |
| ① | 导出图在光标位置**出现光标**，且**热点对齐**（箭头尖端对在光标真实位置，不是左上角对齐） | 目视 + 与关闭态逐像素 diff（关闭态应**逐像素一致**于旧版） |
| ② | 关闭开关后与旧版**逐像素一致** | 像素 diff = 0 |
| ③ | 100% / 125% 两种缩放下位置都正确 | 主屏（100%）与副屏（125%）各截一张 |
| ④ | 光标在**选区外**时不绘制 | 选区不含光标位置 → 导出图无光标 |
| ⑤ | 游戏模式/全屏独占（`CURSOR_SHOWING=0`）下不绘制 | 开游戏模式后截图 → 无光标、不报错 |

**⚠️ 已知风险（请重点观察第 1 张）**：provider 的 helper 是懒启动，域侧只给 **120ms** 预算。**第一张截图可能来不及拿到光标（`cursor:null`）**，第二张起正常。若第 1 张就没有光标，**告诉我** —— 修法是在 `main.js` 启动时按开关预热一次（约 1–2 行，已在方案 §21.3-1 登记）。
**识别路径不画光标是刻意行为**：OCR/翻译/表格/二维码取图时不混入光标。

### 3.3 标注元素二次编辑（S6）

在 `Ctrl+1` 的截图窗里，先画若干标注（矩形/椭圆/箭头/画笔/高亮/文字/序号/水印），然后：

| # | 步骤 | 期望 |
| --- | --- | --- |
| ① | 点选任一标注（含重叠的两张，点公共处） | 出现**虚线框** + 浮动条；重叠时选中**最上层** |

| ④ | 方向键（Shift=10px） | 微调生效；`Ctrl+Z` 一次回到微调前（连续按键合并为一次） |
| ⑤ | 浮动条「删除」/ `Delete` | 删除选中项；`Ctrl+Z` 可撤销 |
| ⑥ | 浮动条「上移/下移」 | 层序变化**同时**反映到屏幕与导出图；`Ctrl+Z` 不串 |
