## 1. 背景与目标

重组前侧栏「设置」组有 6 页（界面设置 / 模型 / 功能设置 / 划词工具 / 热键设置 / 系统设置），另有「个性化」组的外观配色、插件，以及工具箱里的本地搜索、剪贴板历史也承载设置。问题不是单纯页数多，而是**三种粒度混在同一层级**：

- 跨功能的应用设置（界面 / 热键 / 系统）
- 单功能配置页（模型 / 划词工具）
- 同类单功能配置却放在工具箱（本地搜索 / 剪贴板历史）

同时存在同类设置分散（`screenshot.*` 跨 3 页、快捷键双入口、AI 参数跨 4 页）、保存交互四种模式混用等问题。目标：**设置组 6 → 4 页；每个设置唯一入口；同类设置相邻；保存行为一致。**

## 2. 最终信息架构

侧栏 12 项（原 15 项）：

```
快捷功能（新增「快捷键」页签，吸收原热键设置页）
工具箱：翻译 / AI 对话 / 截图历史
工具设置：划词工具 / 本地搜索 / 剪贴板历史     ← 原「个性化」组位置
设置：通用 / 截图与录制 / AI 与模型 / 系统与数据
关于（纯信息页）
```

| 设置页 | 页内结构 | 内容 |
|---|---|---|
| 通用 | 4 个分区 | 外观（主题/主色/圆角/紧凑/皮肤/透明度/自定义 CSS）、界面（语言、缩放说明）、启动与托盘（自启/托盘/游戏模式/日志）、功能模块（OCR/翻译/AI/录屏开关）、软件更新 |
| 截图与录制 | 3 个页签 | 截图与输出（保存目录/命名/历史/截图行为 14 项）、文本识别（OCR 参数与状态、模块停用提示）、录制与贴图（帧率/音轨/目录/贴图穿透） |
| AI 与模型 | 3 个页签 | 供应商、功能模型指派、默认参数（maxTokens / temperature / 默认翻译目标语言） |
| 系统与数据 | 4 个分区 | 软件数据目录、翻译代理、本地诊断、恢复默认设置 |

## 3. 旧 → 新映射

| 旧页面 / 入口 | 去向 |
|---|---|
| 界面设置 + 外观配色 + 插件 + 系统设置·常用 | 通用 |
| 功能设置 | 截图与录制（AI 参数迁出） |
| 功能设置·AI 与翻译 | AI 与模型·默认参数 |
| 模型 | AI 与模型（新增默认参数页签） |
| 热键设置 | 快捷功能·快捷键页签（路由删除） |
| 系统设置 | 系统与数据（常用区块迁到通用） |
| 外观配色、插件 | 路由删除，内容分别并入通用·外观、通用·功能模块 |
| 划词工具 / 本地搜索 / 剪贴板历史 | 工具设置组（页面内容不变） |
| 关于·软件更新卡 | 通用·软件更新（P3）；关于只保留版本信息与跳转入口 |

## 4. 交互规则

1. 开关 / 下拉 / 颜色 / 滑杆：即时保存（`updateSettings` + toast）。
2. 文本 / 数字：失焦（change）保存，不再有页底「保存」按钮（界面设置、外观配色、功能设置、本地搜索的误导性按钮已删除）。
3. 草稿语义区块（模型供应商、划词提示词/自定义功能、本地搜索分类）保留显式保存按钮。
4. 模块关闭时对应设置页签显示停用提示并提供一键开启。
5. 状态轨显示路由：`home` / `settings-function` / `models`（原 4 条，随热键页删除收敛为 3 条）。

## 5. 工程契约与改动面

- 删除路由：`appearance`、`plugins`、`settings-hotkeys`；设置组 4 页 route id 保持不变（`settings-general` / `settings-function` / `models` / `settings-system`），`models` 唯一主进程深链不受影响。

## 6. 决策记录（含未处理项）

| 事项 | 决策 | 理由 |
|---|---|---|
| 工具设置组 | 采纳 | 把「工具（用）」与「单功能配置」分开，设置组只留跨功能设置 |
| 快捷键并入快捷功能 | 采纳 | 原热键页与快捷功能页同源（`functionGroups`），双入口且键表失配 |
| 划词工具 | 保留独立大页，移入工具设置组 | 该页是 2026-07-23 的刻意设计，不拆散内容 |
| 关于·软件更新 | 迁到通用·软件更新（P3） | 跨功能设置归「设置」，关于保持纯信息页 |
| 无设置槽的 4 个快捷键行 | 本轮不修 | 用户明确本轮不动；仍与旧行为一致 |
| `showOrHideMainWindow` 无 UI | 本轮不修 | 同上 |
| e2e 缺 `clipboard-history` | 本轮不补 | 同上；需后续单独立项 |
| 死键 / 孤儿设置键（`screenshot.saveFormat`、`ocr.modelWriteToMemory`、`fixedContent.autoResize/autoOcr`、`record.captureCursor`、`search.pageSize` 等） | 保留不删 | 删除需要 schema + 迁移 + 校验联动，风险高于收益；等对应功能落地或统一清理时再处理 |
| 界面缩放占位行 | 保留 | 显示「自动」，无设置键；与系统 DPI 绑定 |
| design-demos a/b/c 生成物 | 仅同步 `src/content.js` 与 tools 清单 | 生成物是历史视觉原型快照，不属于产品代码 |

## 8. 后续建议

1. 修既有红灯：`settings-effects` / `i18n-main` / `window-security` / `data-root*` 的剪贴板与 conversations 期望、原生 sidecar 构建。
2. 快捷键：补齐 4 个无键功能行或移除其录制器；为 `showOrHideMainWindow` 补入口。
3. 设置搜索：全局搜索键（含页内锚点）是页数收敛后的兜底发现机制。
4. 死键清理：随对应功能补齐或统一删除 + schema 迁移。
