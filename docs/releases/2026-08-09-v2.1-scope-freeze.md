# Highlighter 2.1 范围冻结与候选基线

- **冻结日期：** 2026-08-09
- **冻结提交：** `1a57468188cbbeac949034462512ca10e9062577`
- **开发版本：** `2.1.0-beta.0`
- **目标平台：** Windows 10/11 x64
- **发布形态：** NSIS 安装版与 portable 便携版

`2.1.0-beta.0` 是内部稳定化版本标识，不代表已经发布公开 Beta。公开 Beta 必须满足本文门禁并使用新的版本提交。

## 1. 产品定位

2.1 将 Highlighter 收敛为 Windows 本地优先的截图、OCR、划词与 AI 后处理工具。本阶段不继续扩大功能面，优先完成可信发布、安全边界、诊断和真实环境验证。

## 2. 冻结范围

2.1 只接受以下工作：

- 修复冻结基线上能够复现的正确性、稳定性、性能或兼容性问题。
- 完善版本、CI、签名、Release、安装和回滚门禁。
- 收口 preload、CSP、导航、新窗口、IPC sender/owner 和生产包完整性边界。
- 增加本地诊断、异常退出记录和脱敏验证。
- 为降低回归风险而进行的等价模块拆分；重构提交不得混入产品行为变化。
- 补齐真实 Electron renderer、NSIS/portable 和 Windows 硬件验收。

2.1 不接受以下工作：

- 新增截图、标注、OCR、长截图、贴图或录屏功能。
- 新增 AI 动作、模型能力、服务商或提示词功能。
- 录屏音频、跨平台、云同步、团队协作或插件市场。
- 不服务于上述门禁的大规模 UI 改版或数据格式迁移。

OCR 历史全文搜索、剪贴板兼容模式和 AI 服务商抽象保留为 2.1 稳定发布后的候选项，必须分别评审和提交。

## 8. 本地诊断实施记录

2026-08-09 完成本地诊断闭环：应用日志改为带 session id、版本和事件类型的结构化记录；runtime marker 可在下次启动识别未正常退出，并在正常退出时原子标记 clean。Electron crash reporter 只写本地受管目录且禁用上传。

系统设置页可预览并导出 ZIP。默认白名单仅包含应用/运行时/Windows/显示器摘要、原生组件版本与 SHA-256、轮转日志和最近进程退出记录；不读取配置原文、凭据、AI/划词内容、截图历史、OCR 或录屏媒体。crash dump 默认排除，只有用户勾选并确认后才加入。

自动测试使用假的 API Key、Bearer token、prompt、AI content、用户名路径和数据根路径反解扫描 ZIP；真实 Electron 主进程烟测同时确认 `uploadToServer=false`、设置页安全 IPC、ZIP 可解压以及正常退出 marker。
