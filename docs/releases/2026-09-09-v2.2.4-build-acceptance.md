## 5. 本次改动的现场验证点

1. **OCR 模型校验缓存生效** — 日志出现 `OCR model validation 9ms`。此前每次侧车冷启动需同步读取并 SHA-256 全部三个模型（约 15.4 MB）。
2. **历史落盘已移出 IPC 返回路径** — 日志出现新增埋点 `capture.history-persist action=pin 54ms`，且历史记录正确落盘。
3. **截图尺寸检查不再解码整图** — `capture.interactive mode=image` 的 `captureMs` 仅 0.05 ms。
4. **搜索假服务仅作用于 E2E** — 生产安装包走真实 Everything 路径（v1.4.1.1032，返回 600 条），未受 `HIGHLIGHTER_E2E_FAKE_EVERYTHING` 影响。
5. **分类去重未破坏设置页** — 本地搜索设置页 10 个分类完整渲染（`config.js` 现从 `search-utils.js` 读取）。

## 7. 复现步骤

```powershell
npm ci
npm run build:native
npx electron-builder --config electron-builder.release.cjs --win nsis --x64 --publish never `
  "--config.electronDist=$(Resolve-Path 'node_modules/electron/dist').Path" `
  --config.forceCodeSigning=false --config.win.signExecutable=false
node scripts/verify-electron-fuses.js dist/win-unpacked/Highlighter.exe
Start-Process -FilePath 'dist\Highlighter-Setup-2.2.4.exe' -ArgumentList '/S' -Wait
```
